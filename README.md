# Skills

Mes compétences (skills) Claude, une par fichier. Elles s'enchaînent dans cet ordre :

1. [ba-discovery](ba-discovery.md) — cadrer une demande floue par interview en QCM, produire un Discovery Brief
2. [solution-options-analyst](solution-options-analyst.md) — explorer et comparer des options de solution
3. [solution-security-architect](solution-security-architect.md) — concevoir la solution retenue (données, règles, droits, sécurité, RGPD)
4. [ux-ui-designer](ux-ui-designer.md) — concevoir l'expérience et l'interface
5. [solution-builder](solution-builder.md) — construire la solution incrément par incrément

Autres compétences :

- [pilote-conception](pilote-conception.md) — point d'entrée unique : choisit le parcours, enchaîne les skills jusqu'au bout, avec pause et reprise
- [refonte-outil](refonte-outil.md) — repenser un outil existant (HTML, artefact, Excel) : remplace Discovery, Options et Architect par un seul Dossier de refonte, puis UX/UI et Builder
- [conception-express](conception-express.md) — petite demande : cadrer en 1 ou 2 QCM, construire et livrer dans la même conversation ; si l'outil grandit, passer par refonte-outil puis la chaîne complète
